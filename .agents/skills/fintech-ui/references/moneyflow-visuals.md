# MoneyFlow visual direction

The user supplied four inspiration screenshots, available in `../assets/reference-01.png` through `reference-04.png`. Inspect them when building or reviewing MoneyFlow. They are references for hierarchy and visual treatment, not templates to copy or product requirements.

- Reference 01: Strong data hierarchy, warm off-white content canvas, dark utility sidebar, fine borders, condensed uppercase eyebrow labels, large tabular figures, restrained red and green. Its business payments features and large chart are not MoneyFlow features.
- Reference 02: Airy personal-finance overview, rounded but subtle surfaces, compact summary figures, category labels next to the spending graphic, short recent-activity list. Skip decorative payment card, upsell, investments, calendar, assistant, fictitious comparisons and unsupported trend claims.
- Reference 03: Precise transaction table, crisp black-on-white typography, aligned monetary column and active sidebar item. Skip card numbers, transfer/request flows, excess navigation and monthly comparison percentages unsupported by data.
- Reference 04: Soft warm-grey shell, navy ink and narrow indigo accents, unusually clean transaction rows and spacious main panel. Skip the non-functional cards, line chart and fake account features.

## Synthesis for MoneyFlow

Use a light warm-grey/off-white content canvas, deep ink/navy for text and optional compact desktop rail, and one restrained warm coral or muted red accent for the primary action and selected navigation. Prefer the analytical precision of reference 01 and the personal-finance friendliness of 02–04. Keep contrast stronger than in the softer mockups. Use at most four concise summary metrics, one honest category graphic with exact figures, four account balances, and a legible transaction list. Give the account balances appropriate importance without drawing fictional payment cards. Mobile should preserve the key numbers and the add action while converting table rows into two-line stacked entries. Build an original layout; do not reproduce logos, names, card numbers, layouts or copy verbatim.
